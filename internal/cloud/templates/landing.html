Start in two steps

  1. 1

    Start gusto.

    One command installs it on your computer, starts it and opens it in your browser. Or use gusto cloud and skip it.

  2. 2

    Make a room and add an agent.

    Add a model key on the first page, pick an agent, and ask it something. Invite your team when it works for you.

gusto is a pre-release: it works, and it changes often. Read the quickstart.

On your computer
curl -fsSL https://github.com/getlatentic/gusto/releases/download/v0.1.0-rc.2/install.sh | sh -s -- v0.1.0-rc.2

What you get from day one

  • Shared rooms

    A chat for your team and its agents. Ask any agent by name, and everyone in the room sees its answer and the files it wrote.

  • Any agent

    Claude Code, Codex, OpenCode and more, each on a model you approve. Switch without rebuilding credentials or spend controls.

  • Your apps stay yours

    Each person chooses, app by app, what an agent may use of theirs. It works as them, only for what they ask, and never holds the sign-in.

  • Only the models you approve

    Agents run sealed off. Each reaches its approved model and nothing else, and every connection gusto refused is listed with the reply.

  • Budgets that stop agents

    Each person has a monthly budget, checked before every model call. When it runs out, the agent stops and the room says why.

  • A record of every run

    Administrators see people, spend and what every run did, with what it cost and how long it took.
