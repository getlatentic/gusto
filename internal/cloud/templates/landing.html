How it works

  1. 1

    Make a room

    A shared chat for your team and its agents.

  2. 2

    Add any agent

    Claude Code, Codex, OpenCode and more, each on a model you approve.

  3. 3

    Let it use your apps

    On the agent’s Apps page. It works as you, only for what you ask.

  4. 4

    Keep spend in check

    Each person has a monthly budget, checked before every model call.

One workspace. One set of controls.

  • Your apps stay yours

    Each person lets an agent use their Notion or GitHub. It works as them, only for what they ask. Another person’s request never carries their apps, and the agent never holds the sign-in.

  • Only the models you approve

    Agents run sealed off. Each reaches its approved model and nothing else, and every connection gusto refused is listed with the reply.

  • Budgets that stop agents

    gusto checks each person’s budget before every model call. When it runs out, the agent stops at the next call and the room says why.
