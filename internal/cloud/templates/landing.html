Your team's agents, without a different setup for every one.

Different agents are good at different things. Your team can use Claude Code for one task, Codex for another, and OpenCode or Pi for something else, with the same credentials, approved models, spend controls and activity history around all of them.

  • Claude Code

    Runs in an isolated workspace, on the models and credentials your organisation controls.

  • Codex

    Gets the files and tools it needs without a separate operating model of its own.

  • OpenCode

    An open harness, under the same policies and visibility as the rest.

  • Pi

    Runs alongside the others rather than in an environment of its own.

  • Hermes

    A general-purpose agent, in the same place as the rest.

  • And your own

    Bring an internal or custom harness into the same operating model.

The live demo offers OpenCode, Pi and Hermes on open models. The platform runs the others on the models your organisation connects.

How it works

  1. Pick a harness

    Start with Claude Code, Codex, OpenCode, Pi or another available harness. You choose the agent that suits the work.

  2. Give it a workspace

    The agent gets an isolated computer with the files, tools and context the task needs.

  3. Keep the same controls

    Credentials, model access, network rules and spending limits stay outside the harness, so changing the agent does not mean rebuilding them.

  4. See what happened

    Model calls, files changed, cost and results are recorded in one place.

Change the agent. Keep the controls.

Agent harnesses come and go. Latentic keeps the controls around the harness instead of burying them inside it.

  • Credentials

    Model keys stay outside the agent's computer. The agent reaches a model through a proxy and never holds the key.

  • Models

    Choose which models your people can use, and which harnesses can reach them.

  • Spend

    Set limits for the organisation, a team or a job, and see what each model and harness costs.

  • Network access

    An agent's computer can reach only what you allow.

  • Activity history

    See who started work, which agent ran, which model it used and what it changed.

  • Evidence

    Keep the checks, logs and results with the run that produced them.
